# Практические работы по ИУП — Дыбин А.Е., 4ИСП9-45

МДК.09.01 «Проектирование и разработка веб-приложений» и МДК.05.03 «Тестирование информационных систем».
Все работы выполнены на одном проекте — портале записи на конференции **«Конференции.РФ»** (Python, Flask, SQLite).

## Код
- [app/](app) — итоговая версия приложения (ПР 14): [app.py](app/app.py), [core/](app/core) (работа с БД, валидация), [schema.sql](app/schema.sql), [templates/](app/templates), [static/](app/static) (CSS, JavaScript)
- [run.py](run.py) — запуск из корня
- [seed_demo.py](seed_demo.py) — демо-данные для свежей базы
- [requirements.txt](requirements.txt) — зависимости
- [tests/test_forms.py](tests/test_forms.py) — автотест форм (задание 3 по МДК.05.03)

Версии приложения по этапам лежат в папках работ: ПР 3, ПР 9, ПР 13, ПР 14 (подпапка `app/`).

## Запуск
```bash
pip install -r requirements.txt
python seed_demo.py   # заполнить свежую базу демо-данными (один раз, необязательно)
python run.py         # http://127.0.0.1:5000
```
